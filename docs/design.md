# 设计说明与实验论证

## 1. 信号模型与角度约定

窄带远场平面波，阵列沿 x 轴布放，角度 θ 为来波与阵列**法线**（broadside）
的夹角。M 阵元 ULA 阵元位置（居中放置，居中与否不影响任何协方差类估计）：

```
x_m = (m − (M−1)/2)·d + Δx_m,   m = 0..M−1
```

导向矢量元素 `a_m(θ) = exp(j·2π/λ·x_m·sin θ)`。可选阵元位置误差 Δx_m。

## 2. 协方差

样本协方差采用 MLE 归一化 `C = X X^H / K`，归一化对 MUSIC 谱、特征值
准则与功率估计都没有影响，但能让 C 的对角元直接读作各通道总功率，
SNR 估计直观。每次更新后做 `C ← (C + C^H)/2` 强制精确厄米。

## 3. 增量更新：两种定义与一致性

### 3.1 定长滑动窗口（默认）

维护最近 W 条快拍的环形队列与未归一化和 `S = Σ x_k x_k^H`：

```
新批进入: 对每条 x：若窗口满，S −= x_old x_old^H，N −= 1；
                             S += x x^H，N += 1
C = S / N
```

旧数据在滚出窗口时被**干净地减去**，与“只对窗口内快拍一次性算
`XX^H/W`”逐项相同（浮点上相对误差 1e-12 量级，见
`tests/test_incremental.py`）。代价是要留窗口内全部快拍，内存 O(M²·W)
量级的向量存储（M≤64、W=256 约 0.3 MB）。

### 3.2 指数遗忘因子

按**快拍**逐条加权：已累积 N 条时第 t 条权重 `α^(N−t)`——最新一条
权重 1，每往前一条乘 α。一批 K 条进入时的递推（S 为未归一化和，
由 `C·N` 还原）：

```
S ← α^K·S + Σ_j α^(K−j) x_j x_j^H
N ← α^K·N + Σ_j α^(K−j)
C = S / N
```

无需保留历史快拍（内存 O(M²)）。该定义只取决于快拍序列本身，与
分包方式无关：同一批快拍整批推、切小批推、逐条推得到相同的 C 与
N（浮点 1e-12 量级），并与一次性参考 `forgetting_covariance` 对齐
（见 `tests/test_incremental.py`）。稳态有效快拍数
`N → 1/(1−α)`；取 `α = (W−1)/(W+1)` 使权重分布的平均样本年龄
`α/(1−α) = (W−1)/2` 与长度 W 的滑动窗口相同，公平比较（注意此时
权重和 `1/(1−α) = (W+1)/2`，约为窗口条数的一半）。

> 历史注记：2026-10 之前的实现把遗忘作用在**批**上（整批权重 1、
> 旧和每批只乘一次 α），结果随分包方式变化，详见 §12。

### 3.3 为什么默认 sliding

两者的本质差别是**旧数据的权重消退形状**：

* sliding：旧数据权重是平顶矩形——在窗内权重 1，滚出窗口瞬间为 0，
  窗口之外的历史对估计**严格**无影响；
* forgetting：旧数据权重按 α^t 几何衰减——永不真正为 0，阶跃或野值
  留下的偏差以 α^t 永远拖尾（总权重 α^t·N 有界但不为 0）；且等平均
  年龄下其权重和（有效快拍数）只有矩形窗的一半，MDL/AIC 与 CRB 所
  用的 N 相应更小。

sliding 的协方差就是窗口内快拍的精确 MLE，外部工具只凭窗口数据即可
逐位复算；forgetting 必须保留完整历史才能复算。在本规模下滑动的内
存代价可忽略（§4），故默认 sliding；两种方式都完整支持。

## 4. 跟踪实验（角度阶跃：−20° → +20°）

复现：`python experiments/tracking_experiment.py`
（固定 5 个种子 101/202/303/404/505，M=8、d=λ/2、SNR=15 dB、每 16 条
快拍出一次 D=1 MUSIC 估计）。

* **跟拍延迟**：阶跃后估计连续 3 次落入新角 ±1° 时距阶跃点的快拍数；
* **稳态 RMSE**：阶跃后 6W–12W 区间相对 +20° 的均方根误差；
* 两个场景：`warm` 阶跃前仅 2W 条历史；`settled` 阶跃前已有 10W 条
  （常驻后端长时间运行的典型情形）。

> 下表为 2026-10 遗忘因子修复（§12）后的实测。修复前旧实现按**批**
> 加权，在每 16 条一包的推送下有效记忆被放大约 16 倍，曾测出
> “settled 场景遗忘因子跟拍延迟约 4.6W”的假象；该结论随旧实现作废。

### 实测结果

| 场景 | 方式 | 等效记忆 | 跟拍延迟 P90（快拍） | 延迟/W | 暂态RMSE 0–3W | 稳态RMSE 阶跃后 |
|---|---|---|---|---|---|---|
| warm | 滑动 W=128 | 128 | 80 | 0.63 | 16.70° | 0.0407° |
| warm | 遗忘 α=.9845 | 128 | 57 | 0.45 | 14.21° | 0.0402° |
| warm | 滑动 W=256 | 256 | 144 | 0.56 | 16.28° | **0.0238°** |
| warm | 遗忘 α=.9922 | 256 | 96 | 0.38 | 13.41° | **0.0237°** |
| warm | 滑动 W=512 | 512 | 272 | 0.53 | 16.16° | 0.0155° |
| warm | 遗忘 α=.9961 | 512 | 192 | 0.38 | 13.39° | 0.0159° |
| **settled** | **滑动 W=256** | 256 | **144** | **0.56** | 16.67° | **0.0238°** |
| settled | 遗忘 α=.9922 | 256 | 96 | 0.38 | 13.68° | 0.0237° |
| settled | 滑动 W=128 | 128 | 80 | 0.63 | 17.05° | 0.0407° |
| settled | 遗忘 α=.9845 | 128 | 64 | 0.50 | 14.14° | 0.0402° |
| settled | 滑动 W=512 | 512 | 272 | 0.53 | 16.46° | 0.0155° |
| settled | 遗忘 α=.9961 | 512 | 192 | 0.38 | 13.52° | 0.0159° |

（完整数据含最大值、阶跃前 RMSE：`experiments/results/tracking_results.json`）

### 结论

1. **sliding 的跟拍延迟约 0.53–0.63W，且与阶跃前历史长度完全无关**。
   W=256 默认下：阶跃后约 **144 条快拍**（每 16 条估一次即约 9 次估计）
   持续进入新角 ±1°，稳态 RMSE 约 **0.024°**（M=8、SNR=15 dB）。
2. 修正后的 forgetting 跟拍延迟约 **0.38–0.50W**，同样与阶跃前历史
   长度无关（几何权重的总质量 `N ≈ 1/(1−α)` 有界，旧历史的绝对权重
   随 α^t 衰减）；稳态 RMSE 与 sliding 基本打平。
3. 阶跃**前**的稳态精度 forgetting 略差（等平均年龄下其权重和只有
   窗口条数的一半：0.029° vs 0.028°，W=256 warm）；其指数拖尾永不
   真正归零，野值/阶跃的影响以 α^t 永远残留（有界但非零）。
4. 内存代价（W=256、M=8 约 32 KB；M=64 约 2.1 MB）在本规模下可忽略。

故默认仍为 `sliding / W=256`：协方差即窗口内快拍的精确 MLE、硬边界、
可凭窗口数据逐位复算、有效快拍数不打折（§3.3）。需要 O(M²) 内存或
更在意跟拍延迟时可选 forgetting（修正后其延迟反而略低），注意其
`n_eff ≈ 1/(1−α)` 约为同“等效记忆”窗口条数的一半。

## 5. 源数判定（MDL / AIC）

对样本协方差降序特征值 λ_i，候选信源数 k 的噪声子空间为
{λ_k,…,λ_{M−1}}，记其算术均值与几何均值之比：

```
L(k) = (M−k)·ln( AM(λ_{k:}) / GM(λ_{k:}) )
AIC(k) = 2 N L(k) + 2 k(2M−k)
MDL(k) =   N L(k) + ½ k(2M−k) ln N
```

取使准则最小的 k。FB 平滑时 N 使用等效快拍数（原始 K 乘 2(M−L+1)）。
高 SNR、K 足够时 MDL 一致地给出真实源数（测试：3 源、20 dB、800 条）。
调用方也可以直接指定整数源数；源数 ≥（子阵）阵元数会被拒绝。

## 6. 前后向空间平滑

子阵长度 L 可配（默认 ⌈2M/3⌉），共 M−L+1 个前向子阵与同数个后向子阵
（后向 `J C_f^H J`，J 为交换阵），平均后秩恢复为 min(D, L)，可分辨的
最多非相干信源数为 L−1；相干源用平滑恢复秩。开启平滑后 MUSIC 在 L 维
子阵几何上完成，CRB 的阵元数、孔径随之按子阵计算，等效快拍数乘
2(M−L+1)。指定源数达到 L 会得到明确错误（要求增大子阵长度）。

## 7. MUSIC 扫描与细化

粗扫网格 `θ_min + i·step`（缺省 −90°…90°、0.5°，点数上限 20 万），
谱 `P(θ) = 1 / (a^H E_n E_n^H a)`；取严格局部极大的最强 D 个峰，每峰
在相邻网格构成的 ±step 区间内做 50 次黄金分割一维搜索（区间收缩
0.618^50 ≈ 5e−11 倍步长），精度比步长细十个数量级，远超“细一个数量级”
的要求。测试中真值偏离粗网格（18.37°、步长 0.5°）时误差仍 <0.05°。

## 8. CRB

单信源、空间白高斯噪声、确定性（条件）模型，对方位角（弧度）：

```
CRB(θ) = 1 / [2 N · SNR · (D^H P_a^⊥ D)]
D = da/dθ = j k x cosθ · a
```

多源结果中逐源给出：由特征分解取噪声功率 σ²、向量化协方差最小二乘
拟合各源功率 P_i，SNR_i = P_i/σ²；CRB 标准差（度）随每条估计返回，
带真值时再给 `|θ̂−θ| / CRB_std`。SNR 0→20 dB、每点 40 次重复的实测：
RMSE 随 SNR 严格下降，高 SNR 段（15/20 dB）该比值约 0.9–1.2，<3。
开启平滑时按子阵几何与等效快拍数计算（平滑处理增益未额外计入，估计偏
保守）。

## 9. 栅瓣模糊

理想 ULA 的导向相位只含 `(d/λ) sin θ`。当 d > λ/2 时存在可见别名：

```
sin θ′ = sin θ ± n·λ/d,   |sin θ′| < 1
```

服务对每个估计角枚举全部可见别名（n=1,2,…）随结果返回
（`grating_pairs`），并置 `grating_ambiguous: true`；d=λ、θ=10° 时
别名 θ′≈−56.6°。带位置误差的阵列无严格栅瓣，不报此标志。

## 10. 合成的逐位复现

只使用 `numpy.random.default_rng(seed)`，绘制顺序固定（先 M×K 噪声，
再信源包络；相干组先抽公共包络再抽各源固定相位），所有缩放系数确定。
同 (参数, seed) 的返回数组 `np.array_equal` 逐位相同（测试同时与
HTTP 响应交叉验证）。相干源共享一个 CN(0,1) 包络并乘种子决定的固定
相位，秩严格为 1。

## 11. 并发与持久化

* 每个会话一把可重入锁；FastAPI 的同步路由跑在线程池，同会话并发追加
  被串行化，最终状态等价于某一先后顺序的串行追加（测试直接比对落盘
  窗口内容等于 AB 或 BA 之一，且 C 与窗口自洽）；
* `batch_id` 去重集合与 C/窗口在同一个 `state.npz` 中，经临时文件 +
  `os.replace` 原子落盘；同号批次重复提交不重计；
* 结果写 `results.jsonl`（append + fsync），版本号由既有记录数 +1
  得到，重启后连续；
* SSE 推送用订阅时捕获的事件循环 `call_soon_threadsafe` 跨线程投递，
  慢消费者丢旧保新；
* 启动时扫描数据目录恢复全部会话（协方差状态懒加载）。

## 12. 遗忘因子按批加权缺陷的修复与旧会话迁移（2026-10）

### 12.1 缺陷

旧实现的递推是 `C ← (α·N·C + X X^H)/(α·N + K)`、`N ← α·N + K`：遗忘
作用在**批**上——每来一批，整批 K 条权重都是 1，旧和只乘一次 α。
于是累积结果随分包方式变化，不是快拍序列的确定函数。同一份 600 条
快拍（−20° 段 300 条接 +20° 段 300 条，α=0.98）：

| 推法 | 估计角 | 有效快拍数 |
|---|---|---|
| 整块 600 条 | −18.97° | 600.0 |
| 每包 16 条 | +19.63° | 420.7 |
| 逐条 | +19.99° | 50.0 |
| 正确定义（按快拍逐条遗忘） | +19.99° | 50.0 |

源数判定（MDL/AIC）与 CRB 都以这个有效快拍数为输入，因此同样随分包
漂移。缺陷长期未被发现，是因为 α=1 时两种定义恰好重合（α^K=1、
Σα^(K−j)=K），而 α=1 正是回归测试唯一覆盖的情形。

### 12.2 修复后的定义（口径 v2）

按快拍顺序、最新一条权重为 1、每往前一条乘 α（§3.2 的递推）。一批
K 条进入时旧和整体乘 α^K，批内第 j 条权重 α^(K−j)。性质：

* 与分包方式无关，整批/切批/逐条推入结果相同（浮点 1e-12 量级）；
* 与“对全部快拍按定义一次性计算”的 NumPy 参考相对误差 1e-9 以内；
* `α^K` 下溢到 0 是定义允许的（旧数据权重确实为 0），α=0.5、单批
  一万条不出 NaN、不除零（最新一条权重恒为 1，`n_eff ≥ 1`）；
* α=1 时退化为增长样本协方差，与 `XX^H/K` 逐元素一致（旧行为中唯
  一正确的情形，保持兼容）。

### 12.3 口径标记

每个累加器状态带 `rule` 标记随 `state.npz` 落盘，会话状态
（`GET /sessions/{id}` 与列表）暴露 `update_rule` / `update_frozen`：

* `sliding-window-v1`：定长滑动窗口（语义未变，旧状态直接兼容）；
* `forgetting-snapshot-v2`：按快拍遗忘（现行定义）；
* `forgetting-batch-v1`：按批遗忘（旧口径，只用于识别升级前状态）。

每次估计的结果记录也带 `update_rule`，历史记录因此自描述。

### 12.4 旧会话迁移：候选方案与取舍

前提约束：服务从不保存遗忘方式下的原始快拍，旧状态里只有按旧口径
累积的 (C, N)，**无法换算**成 v2 口径；同时不允许把两种口径悄悄拼
在同一个累积状态里。

* **候选 A：旧会话沿用旧算法继续追加。** 会话内保持自洽、不破坏
  “重启续追加”。放弃：旧口径的量随分包方式变化，根本不是数据的
  确定函数，外部无法复算；继续追加只会在这个 ill-defined 的度量上
  越积越多，且新旧会话的数字永远无法互相对照——保留一条已知错误
  的更新路径只会制造更多需要解释的数据。
* **候选 B：从某个分界点起切换新算法并标出分界。** 看似平滑。放弃：
  切换点之前累积的 (C, N) 是按批口径的，无法重解释为新口径的未归
  一化和（原始快拍不存在），分界之后的累积实际上仍是“旧口径历史
  + 新口径增量”的混合体——即使标了分界，协方差本身在两种定义下
  都没有意义，正是要避免的口径拼接。
* **候选 C（采用）：旧会话冻结为只读，新数据另开会话。** 旧会话状
  态与历史结果原样保留、可列出、可按版本号逐字读出、可继续在既有
  协方差上出估计（结果带 v1 标记）；新的快拍追加一律拒绝
  （409 `session_frozen`，消息指引新建会话）。任何时刻一个会话只
  按一种口径累积，口径从会话状态直接可读。

升级后的具体行为：

1. 启动扫描数据目录时，凡 `state.npz` 中 `kind=forgetting` 且无
   `rule` 标量的会话识别为 `forgetting-batch-v1`，加载为只读状态；
2. 这类会话：可列出、可查状态、历史结果逐字保留（`results.jsonl`
   从不改写）、可继续出估计；`POST /batches` 回 409；历史批次号的
   重复提交仍按幂等回报（`deduplicated: true`，不改变任何状态）；
3. 升级前创建但从未收到过快拍的遗忘会话没有任何旧口径累积，直接
   按 v2 开始（无口径可混）；
4. 新建遗忘会话一律 v2；滑动窗口会话不受影响，照常续追加。

测试：`tests/test_forgetting_v2.py` 用升级前格式的数据目录真实启动
服务核对以上全部行为；`tests/test_incremental.py` 核对 v2 与一次性
定义/外部 NumPy 参考的 1e-9 对齐、极端参数（α=0.5、单批一万条）不
出 NaN。
